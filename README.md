# Personal Blog Web Application

A personal blog website developed using Python Flask.

## Features
- User Registration and Login
- Create, Edit and Delete Blog Posts
- Comment System
- SQLite Database
- Responsive Design using Bootstrap
- Form Validation

## Technologies Used
- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- JavaScript
- Bootstrap

## Installation

Install the required packages:

pip install -r requirements.txt

## Run the Application

python run.py

## Project Description

This project allows users to register, log in, publish blog posts, edit or delete their posts, and add comments.
